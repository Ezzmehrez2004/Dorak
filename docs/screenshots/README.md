## How to add more (Chrome or Edge)

1. Open the site and log in (demo customer `01000000001`, password `demo1234`).
2. Press F12, then Ctrl+Shift+M to open the device toolbar.
3. Choose "Responsive" and type the width: 375, 768 or 1440.
4. Open the three-dot menu in the device toolbar and choose "Capture full size screenshot".
