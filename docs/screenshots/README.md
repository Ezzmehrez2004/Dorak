# Screenshots

Save the screenshots for the submission in this folder.

## How to capture them (Chrome or Edge)

1. Run `npm run dev` and open the app.
2. Press F12 to open developer tools, then Ctrl+Shift+M (Cmd+Shift+M on Mac) to open the device toolbar.
3. Choose "Responsive" and type the width: 375, 768 or 1440.
4. Open the three-dot menu in the device toolbar and choose "Capture full size screenshot".

Log in first with the demo account `01000000001` / `demo1234` (or sign up), because the join form and "My turn" need an account.
